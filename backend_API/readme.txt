СТРУКТУРА API
==============

Домен: https://sollersdev.ru/


ЭНДПОИНТЫ
----------

/api/v1/sections                           - список всех разделов каталога (массив секций)
/api/v1/sections/flat                      - список всех разделов каталога в плоском виде
/api/v1/sections/tree                      - список всех разделов каталога в иерархическом виде
/api/v1/products/{product_id}              - получить продукт по ID
/api/v1/products?filter1=value1&filter2=value2 - пакетное получение продуктов с фильтрацией

ЗАМЕЧАНИЯ ПО КАТАЛОГУ
----------------------

1. Структура каталога доступна по ссылке: https://outdoor-mebel.ru/catalog/

2. Секция "Террасная доска из ДПК" содержит как доски, так и аксессуары.
   Возможно потребуется добавить дополнительные свойства продуктов в базу битрикса.

3. Продукт может быть в дочерней секции, но не отмечен как часть родительской.
   Это может потребовать изменения логики выборки.


ЗАМЕЧАНИЯ ПО ПРОДУКТАМ
-----------------------

1. preview_picture и detail_picture пока не синхронизированы (URL отсутствуют)

2. Цены - массив (Bitrix позволяет несколько типов цен)
   Сейчас думаю лучше упростить до одной цены

3. preview_text может быть в формате html или text

4. Возвращаются только активные и доступные продукты

5. Текстуры временно хранятся в статике API, а не в БД Bitrix

6. ТОРГОВЫЕ ПРЕДЛОЖЕНИЯ (ВАЖНО):
   - Bitrix поддерживает товары с множеством вариаций
   - Для каждого варианта нужны свои: preview, цена, текстуры
   - Структура продукта ИЗМЕНИТСЯ - добавится массив trade_offers, и скорее всего в него должны переахать цены, превьюшки, текстуры.
   - Это приоритетная задача, так как меняет интерфейс API
   - Пример https://outdoor-mebel.ru/terrasnaya-doska-iz-dpk/terrasnaya_doska_aiwood_150kh25kh6000_4000_3000mm_brashirovannaya_dvustoronnyaya_velvet_m_pog/terrasnaya_doska_aiwood_150kh25kh6000_4000_3000mm_brashirovannaya_dvustoronnyaya_velvet_seryy_m_pog/



ФИЛЬТРЫ
========

Параметры применяются последовательно - возвращается пересечение по всем условиям.

-------------------------------------------------------------------------------

ПАРАМЕТРЫ ФИЛЬТРАЦИИ (GET-параметры)
--------------------------------------

section_id
    Фильтр по id секции каталога.
    Возвращает все продукты в данной секции и дочерних секциях каталога.
    Примечание: Из-за особенностей структуры каталога, возможно целесообразно
    отказаться от поиска в дочерних секциях.

ids
    Фильтр по списку id продуктов.
    Формат: список через запятую
    Пример: ids=196435,198661,198662

price_min
    Фильтр по минимальной цене.
    Значение включается в диапазон.

price_max
    Фильтр по максимальной цене.
    Значение включается в диапазон.

tags
    Список тегов через запятую.
    Примечание: Из-за особенностей структуры каталога не всегда возможно
    точно определить нужный продукт. Для этого используется специальная
    сортировка по дополнительным параметрам.
    
    Доступные теги:
    - terrasnaya_doska - выборка всех продуктов, содержащих в названии
      "Террасная доска"

-------------------------------------------------------------------------------

СОРТИРОВКА
------------

sort
    Сортировка продуктов по одному из доступных полей.
    
    Доступные поля:
    - sort   (по умолчанию)
    - id
    - name
    - price

sort_order
    Порядок сортировки.
    
    Доступные значения:
    - ASC   (по умолчанию) - возрастание
    - DESC                 - убывание

-------------------------------------------------------------------------------

ПАГИНАЦИЯ
-----------

limit
    Количество продуктов на странице.
    По умолчанию: 50
    Максимум: 500

page
    Номер страницы.
    По умолчанию: 1
    Примечание: Если значение превышает количество страниц,
    возвращается последняя страница.

РЕСУРСНЫЙ МЕНЕДЖЕР
===================

Для того чтобы не обрабатывать запросы вручную, написан ресурсный менеджер.
Он берет на себя общение с сетью и загрузку текстур, а также в будущем будет
дополнительно кэшировать данные.
Написан в асинхронном стиле.




ИНТЕРФЕЙС И СУЩНОСТИ
---------------------

FilterType (enum)
    Определяет список возможных фильтров

SORT_FIELDS (enum)
    Определяет список возможных параметров сортировки

SORT_ORDER (enum)
    Определяет список возможных порядков сортировки


КЛАСС FILTER
-------------

Класс для создания фильтров.

Пример использования:
    let price_filter = new Filter(FilterType.PRICE_MAX, 1000)
    let sort_filter = new Filter(FilterType.SORT, SORT_FIELDS.NAME)
    let sort_order_filter = new Filter(FilterType.SORT_ORDER, SORT_ORDER.ASC)


ПРЕССЕТЫ (PRESETS)
-------------------

Для удобства работы предлагается создавать список пресетов.
Сейчас он один, но в дальнейшем можно расширить.

Пример:
    let preset_filters = Presets.terrasnaya_doska_dpk()

ЗАГРУЗКА ТЕКСТУР
------------------

Текстуры загружаются с помощью THREE.TextureLoader() асинхронно.
После загрузки всех текстур поле isTextureLoadedSuccessed становится true.

Особенность: При пакетном получении ресурсов текстуры загружаются фоново по чанкам.
Возможна ситуация, когда нужная текстура еще не прогрузилась, а уже требуется.
Для этого предусмотрен ручной вызов метода.


МЕТОД loadTextures()
---------------------

async loadTextures(force_reload = false)

Параметры:
    force_reload - перезагружает текстуры, даже если они уже были загружены.

Возвращает:
    true  - текстуры успешно загружены
    false - не удалось загрузить ресурсы


КЛАСС RESOURCEMANAGER
======================

МЕТОДЫ
--------

async getResources(...filters)
    Параметры:
        ...filters - фильтры для запроса

    Возвращает при успехе:
        {
            products: [],    // массив продуктов
            total: 0,       // всего записей
            page: 1,        // текущая страница
            pages: 1,       // всего страниц
            limit: 50       // лимит на страницу
        }
    
    Возвращает при ошибке:
        null

    Особенности:
        - Начинает фоновую загрузку текстур по чанкам
        - Возвращает результат сразу, не дожидаясь загрузки текстур
        - Внимание: текстуры занимают видеопамять. Возможно, в будущем
          потребуется отказаться от фоновой загрузки.

    
    Примеры:
    let manager = ResourceManager()

    let dpk_resources = manager.getResources(...Presets.terrasnaya_doska_dpk())

    let dpk_resources_with_price = manager.getResources(...Presets.terrasnaya_doska_dpk(),
                                                        new Filter(FilterType.PRICE_MAX, 1000),
                                                        new Filter(FilterType.PAGE, 2))

    let section_reaources =  manager.getResources(new Filter(FilterType.SECTION_CODE, ""terrasnaya-doska-iz-dpk""),
                                                  new Filter(FilterType.SORT, SORT_FILEDS.PRICE),
                                                  new Filter(FilterType.SORT_ORDER, SORT_ORDER.DESC),
                                                  new Filter(FilterType.LIMIT, 10))
